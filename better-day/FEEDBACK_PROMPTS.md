# Better Day Feedback Prompts

Use these prompts when asking colleagues to review the prototype.

## First Reaction

1. Does the app feel like a reflective workday simulation rather than a quiz or survey?
2. Does the tone feel adult, practical and non-moralising?
3. Does the visual design feel credible enough for ITaLI colleagues to engage with?

## Scenario Realism

1. Which scenes felt recognisable from ITaLI work?
2. Which scenes felt generic, exaggerated or off-target?
3. Were any teams or role postures represented inaccurately?
4. Did the system pressures feel believable?

## Decision Quality

1. Did each decision feel like a real trade-off?
2. Were any options too obviously “right” or “wrong”?
3. Did the consequences make sense?
4. Did delayed consequences make the day feel connected?

## Reflection Value

1. Did the noticing pauses help or interrupt the flow?
2. Did repair opportunities feel constructive rather than punitive?
3. Did the end-of-day profile feel evidence-based?
4. Were the “next small moves” specific enough to try tomorrow?
5. Would you use the final Copilot/GenAI prompt for a reflection activity?

## Improvement Suggestions

1. What should be removed?
2. What should be made more specific?
3. What should be more visually engaging?
4. What would make this more useful for a team workshop or professional learning activity?
